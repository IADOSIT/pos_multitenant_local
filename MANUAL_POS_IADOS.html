Requisitos del Sistema

Modo Offline (EXE Instalador)

Cualquier tablet, celular o computadora en la misma red puede usar el sistema. Solo necesitan un navegador (Chrome, Edge o Firefox) y la dirección IP del servidor.

Módulo POS — Punto de Venta

El corazón del sistema. Desde aquí se gestionan todas las ventas del negocio de forma rápida y sin errores.

Flujo de una venta completa

Abrir caja → Seleccionar mesa → Agregar productos → Confirmar pedido → Seleccionar método de pago → Imprimir ticket → Dar cambio → Venta registrada

Carrito de compras

  • Buscar por nombre, SKU o código de barras
  • Agregar cantidades con botones + / –
  • Aplicar descuento por producto o global
  • Total con impuestos desglosados en tiempo real

Métodos de pago

  • Efectivo — Calcula cambio exacto con pad de billetes ($10, $20, $50, $100, $200, $500)
  • Tarjeta — Registra el monto cobrado por terminal bancaria
  • Transferencia — Registra referencia del pago
  • Pago Mixto — Combina efectivo + tarjeta + transferencia en una sola venta

Impresión de ticket

  • Ticket automático al finalizar la venta
  • Reimpresión disponible desde módulo Pedidos
  • Compatible con impresoras térmicas de 58mm y 80mm

Módulo Mesas

Gestión completa del salón del restaurante con vista en tiempo real del estado de cada mesa.

Vista de mesas

  • Mapa visual de todas las mesas del local
  • Estado en tiempo real: Libre / Ocupada / Con pedido pendiente
  • Color distintivo por mesero asignado

Funciones principales

  • Asignar mesero — Define quién atiende cada mesa
  • Juntar mesas — Para grupos grandes

  • QR de mesa — Genera e imprime el código QR para Self Order
  • Zonas — Terraza, Salón, Bar, Privado, etc.
07

Self Order — Pedido por QR

Sistema de autoservicio donde el cliente hace su pedido desde su propio celular escaneando el código QR de su mesa. Sin app adicional. Sin registro. Sin fricción.

¿Cómo funciona?

Cliente escanea QR en la mesa con su cámara → Se abre el menú en el navegador del celular → Cliente selecciona productos y confirma → Mesero recibe notificación inmediata en el POS → Mesero confirma y manda a cocina → Al cobrar, se envía encuesta de satisfacción automática

Beneficios clave

  • Reduce el tiempo de atención hasta un 50%
  • Elimina errores en la toma de órdenes
  • El mesero puede atender más mesas al mismo tiempo
  • El cliente no espera para ordenar

Dashboard Self Order

  • Total pedidos por QR, ticket promedio, mesa más activa
  • Tiempo promedio de confirmación por mesero
  • Encuestas: calificación de servicio y comida (1-5 estrellas)
💡 Para que funcione desde celulares externos: El admin debe acceder al POS usando la IP de red del servidor (ej. http://192.168.1.X:3000), no desde localhost.

Módulo Caja

Control completo del flujo de efectivo del negocio con cierre de caja profesional.

Ciclo de caja

Apertura (fondo inicial) → Ventas del día (automático) → Entradas/Salidas manuales → Corte: conteo físico vs esperado → Cierre y reporte imprimible

Apertura

Registra el fondo inicial en efectivo, el responsable y la hora de apertura.

Entradas y salidas manuales

  • Retiros para pago de proveedores o gastos del día
  • Entradas para cambio de billete o reposición de fondo
  • Cada movimiento queda registrado con fecha, hora y responsable

Corte de caja

  • Total esperado calculado automáticamente
  • El cajero ingresa el total real contado
  • Cálculo automático de diferencia (sobrante o faltante)
  • Reporte imprimible para el cierre del día

Respaldo y Restauración

Respaldo manual

Ir a Configuración → Respaldo → Descargar archivo .sql con todos los datos. Guárdalo en USB, nube o correo.

Restauración

En caso de reinstalación, importa el archivo de respaldo. Todos los datos se restauran: ventas, productos, configuración.

⚠️ Recomendación: Realiza un respaldo al menos una vez por semana y guárdalo fuera del equipo servidor.

Preguntas Frecuentes

¿Funciona sin internet?

Sí. El modo offline (instalador EXE) funciona completamente sin conexión. La base de datos y el servidor están en el mismo equipo.

¿Puedo usar el sistema desde mi celular o tablet?

Sí. Desde cualquier dispositivo en la misma red Wi-Fi accediendo por la IP del servidor: http://IP-SERVIDOR:3000

¿Cuántos usuarios puedo tener?

Ilimitados. No hay costo adicional por número de usuarios ni sucursales.

¿Puedo importar mi catálogo de productos desde Excel?

Sí. El sistema acepta CSV exportados desde Excel con los campos: SKU, nombre, precio, costo, categoría y más.

¿Qué pasa si se va la luz?

Al restaurar la energía, los servicios de Windows reinician automáticamente. Los datos guardados están intactos.

¿Funciona en Mac, Linux o iPad?

El instalador EXE es para Windows. El acceso desde navegador funciona en cualquier sistema: Mac, Linux, iOS, Android.

¿Tiene soporte para facturación CFDI?

Actualmente genera tickets de venta. La integración CFDI está disponible como módulo adicional. Consulta a tu asesor iaDoS.
